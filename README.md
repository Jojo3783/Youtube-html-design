# YouTube Clone (HTML & CSS)

A static frontend clone of the YouTube desktop homepage. This project was built to practice fundamental web development concepts including page layout, CSS positioning, and element structuring.

## 🚀 Features

* **Header Section:** Includes the hamburger menu, YouTube logo, search bar with tooltip hover effects, and notification icons.
* **Sidebar Navigation:** Vertical layout with flexible navigation items.
* **Video Grid:** A responsive grid layout displaying video thumbnails, timestamps, channel avatars, and metadata.
* **Styling:** Custom CSS for hover states, rounded images, and typography (Roboto font).

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and div-based layouts.
* **CSS3:**
    * Flexbox & CSS Grid for alignment.
    * `object-fit` properties for thumbnail handling.
    * `position: absolute/relative` for timestamps and tooltips.
    * Block vs. Inline-block element management.

## 📚 Learnings

Through this project, I gained a deeper understanding of:
* **Nested Layouts:** Breaking down a complex design into vertical and horizontal containers.
* **CSS Display Properties:** Differences between `block`, `inline`, and `inline-block`.
* **Image Handling:** Using `object-fit: cover/contain` to manage aspect ratios within containers.
